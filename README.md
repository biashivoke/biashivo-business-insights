# Biashivo Business Insights

**Know your numbers. Grow your business.**

Biashivo Business Insights is an educational website helping small and medium-sized business owners in Kenya and across Africa understand their business finances, improve recordkeeping, manage customer payments, and make informed business decisions.

## What You'll Find

- Practical guides for managing small businesses
- Simple explanations of sales, expenses, and profit
- Tips for avoiding common financial mistakes
- Educational articles on business growth and financial management
- Updates about the upcoming Biashivo business management platform

## Technology

This website is built with Astro and generates static HTML pages.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:4321/` in your browser.

## Production Build

```bash
npm run build
```

The generated website files are saved in the `dist/` directory.

## Website Structure

- `src/pages/index.astro` — Homepage
- `src/pages/articles/` — Educational articles
- `src/pages/privacy-policy.astro` — Privacy Policy
- `public/` — Static assets
